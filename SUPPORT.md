# Support

## Questions

Open a GitHub Discussion or issue in the relevant repository. Include:

- Repository and version or commit
- Environment (OS, toolchain versions)
- Minimal reproduction

Do not include private hostnames, LAN or overlay IPs, `/home/<user>` paths, credentials, counterparty data, or secrets.

## Scope

Stable libraries get best-effort community support. Experimental work is
research, not a support commitment.
