# Corbet FOSS

Truly open-source shared code. OSI-approved licenses only
(MIT, Apache-2.0, LGPL, AGPL) — anything source-available lives in
`corbet-libs`, anything single-product stays with its product.

Corporate reviewers get org-at-a-glance assurance: everything here is
open source, no BUSL/FSL taint, per-repo `LICENSE` + SPDX on top.

## Contributing

Default instructions in `CONTRIBUTING.md`. The canonical Individual
Contributor License Agreement for this organization is version 1.0 at
[`cla-v1.0`](https://github.com/corbet-foss/.github/blob/cla-v1.0/CLA.md).
The pull-request affirmation is the acceptance record. LGPL contributions
stay LGPL; outbound relicensing needs explicit agreement, never silence.

## Security

Report vulnerabilities through the affected repository's private GitHub
security advisory form.
